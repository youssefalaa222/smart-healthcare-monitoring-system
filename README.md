# Smart Healthcare Monitoring System – Graduation Project

**Logical Design for the Integration of Acetone-Level Monitoring with Continuous Glucose Sensors for Enhanced Diabetes Management**

Graduation Project II (MGT_420II – Computer-Based Information Systems), Faculty of Management Sciences, MSA University – Spring 2026.

## Overview
An integrated healthcare monitoring system that combines continuous glucose monitoring (CGM) with real-time acetone detection, so early signs of ketosis and diabetic ketoacidosis (DKA) can be detected before they become severe. The design uses wearable biosensors, an ESP32 microcontroller, cloud storage and a mobile application, with automatic alerts to patients and healthcare providers.

## What the project covers
- Business case and problem analysis
- Functional requirements and the 4Ws framework
- System analysis using DFD, ERD and UML modeling
- Use Case, Activity and Sequence diagrams for system workflows
- Class design and logical system design
- Screen/dialogue specifications with traceability between requirements and models
